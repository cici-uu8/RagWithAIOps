### 2. 过程记录文档（14 KB）

**文件路径**：`SuperBizAgent_过程记录文档.md`

**内容概要**：
记录了开发过程中遇到的 6 个主要问题及解决方案：

1. **Milvus content 字段长度限制导致长文档索引失败**
   - 现象：单个 chunk 超过 varchar(8000) 限制
   - 解决：实现 atomic hardcap，截断到 ≤6000 bytes

2. **DashScope embedding API 批量调用返回 400 错误**
   - 现象：批量请求被拒绝
   - 解决：实现分批处理，每批最多 10 条

3. **WeKnora Go 代码无法直接接入 Python 主链路**
   - 现象：语言栈不同，无法直接复用
   - 解决：按字段语义复制 + 最小 Python 化

4. **混合检索的 BM25 和向量检索分数量纲不一致**
   - 现象：分数范围不同，无法直接相加
   - 解决：采用 RRF (Reciprocal Rank Fusion) 算法

5. **P5 文档级去重的候选池大小设计**
   - 现象：候选池太小覆盖不足，太大影响性能
   - 解决：引入 doc_oversample_factor 参数（默认 4）

6. **异步文档处理 Worker 的状态同步问题**
   - 现象：状态更新和队列投递之间存在时间窗口
   - 解决：先投递后更新 + 状态确认机制

**特点**：
- 每个问题都有：现象、原因、解决过程、参考来源、经验教训
- 解决过程详细记录了"首先尝试 → 然后尝试 → 最终解决"的完整路径
- 经验教训总结了通用的排查思路和避免方法
