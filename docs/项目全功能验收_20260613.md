## 判定口径

| 状态 | 含义 |
|---|---|
| PASS | 已通过实际命令、浏览器或 API 检查验证 |
| FAIL | 已验证存在功能、体验或契约问题 |
| BLOCKED | 因外部依赖、配置、数据或前置条件缺失无法完整验收 |
| PARTIAL | 主要链路可用，但有明确子功能缺口 |
| PENDING | 尚未执行 |
| N/A | 不在本轮电脑端验收范围内，不计入通过率 |
