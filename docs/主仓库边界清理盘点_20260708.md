## 6. 小白解释

这次不是“打扫磁盘”，而是先给杂物贴标签。

真正危险的是两件事：

- 有些东西看起来像垃圾，其实是独立 Git 仓库或历史成果，一删就没了。
- 有些文件在父目录看起来是 untracked，但在 SuperBizAgent 新工作线里已经是正常 tracked 文件，不能重复迁移。

所以本轮只做盘点：哪些已经纳入当前线、哪些只是历史 closeout、哪些是大目录需要 owner 决策。下一步要动文件时，再单独开迁移 PR。
