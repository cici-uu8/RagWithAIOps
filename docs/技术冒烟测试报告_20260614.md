## 本轮修正点

### 1. 对话 422

原脚本请求：

```json
{"query": "CPU 使用率过高怎么办"}
```

实际 `/api/chat` 使用 `ChatRequest`，必需字段为：

```json
{
  "Id": "smoke-chat-...",
  "Question": "CPU 使用率过高怎么办",
  "SelectedKbIds": ["process_digital_dept"],
  "ScopeSource": "user_selected"
}
```

修正后：`POST /api/chat` 返回 200。

### 2. 权限申请 400

原脚本硬编码：

```json
{"resource_type": "database", "resource_id": "mysql_production", "action": "read"}
```

实际流程应先调用 `GET /api/permission-requests/resources` 获取可申请资源，再选择真实 catalog 中的未授权 action。

修正后：

- `GET /api/permission-requests/resources` 返回 200
- `POST /api/permission-requests` 返回 200
- `GET /api/permission-requests/mine` 返回 200

### 3. 权限审批 405

原脚本调用：

```text
GET /api/permission-requests?status=pending
```

实际 Admin 审批入口为：

```text
GET /api/admin/permission-requests
POST /api/admin/permission-requests/{request_id}/approve
```

修正后：待审批列表和审批通过均返回 200。

### 4. 执行看板 404

原脚本调用了不存在的后端操作历史端点：

```text
GET /api/enterprise/dashboard/operations
```

当前桌面执行看板是静态入口消费 SSE：

```text
GET /static/enterprise-dashboard.html
```

修正后：页面加载返回 200。

### 5. 部门管理 404

原脚本调用了不存在的成员端点：

```text
GET /api/admin/departments/dept_1/members
```

当前 Admin 部门能力为：

```text
GET /api/admin/departments
PATCH /api/admin/departments/{department_id}/resource-scope
```

修正后：部门列表返回 200。

### 6. Shadow metrics 404

原脚本调用：

```text
GET /api/enterprise/shadow/metrics
```

实际端点为：

```text
GET /api/shadow-metrics
POST /api/shadow-metrics/reset
```

修正后：Shadow metrics 返回 200。
