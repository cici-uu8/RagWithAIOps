## 1. 任务定位

本任务只确认主 checkout 中哪些文件应该保留、迁移或继续待确认。

硬边界：

- 不删除任何文件。
- 不移动任何文件。
- 不在主 checkout 继续开发。
- 不把主 checkout 切到其他分支。
- 不把 runtime 输出、实验输出、计划实验目录直接提交到主线。

当前只读观察到：

```text
main_checkout = /Users/cici/oncall agent/super_biz_agent_py-release-2026-03-21
parent_branch = enterprise2
superbiz_branch = enterprise3
state = dirty
safe_worktree_for_docs = /Users/cici/oncall agent/.worktrees/main-boundary-cleanup
```

说明：父目录 Git 显示为 `enterprise2`，SuperBizAgent 子仓库 Git 显示为 `enterprise3`。无论看哪一层，原则都一样：主 checkout 不是 main，不继续写入；新工作开独立 worktree。
